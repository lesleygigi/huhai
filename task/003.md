# Task 3：Ink 剧情入口与基础规范 ✅

## 任务目标

建立《胡亥模拟器》的 Ink 剧情入口和基础脚本规范，让后续前端播放器可以稳定读取剧情、变量、标记和演出标签。

本任务只处理 Ink 剧情脚本本身，不实现前端播放器、不接入 Ink 编译链路、不迁移完整章节。

## 任务范围

需要落地的文件：

```text
story/main.ink
story/prologue.ink
```

主要工作：

- 在 `story/main.ink` 中定义全局变量。
- 在 `story/main.ink` 中定义基础标记列表。
- 设置剧情入口，使游戏进入序章。
- 在 `story/prologue.ink` 中迁移序章核心可玩片段。
- 统一 Ink 演出标签格式。

不包含：

- 前端 UI 实现。
- `inkjs` 加载逻辑。
- Ink 编译脚本。
- 完整序章全文迁移。
- 第一章及后续章节迁移。

## Step 3.1：编写 `story/main.ink`

### 目标

集中定义全局变量、基础标记列表，并将剧情入口跳转到序章。

### 实施内容

在 `story/main.ink` 中定义以下数值变量：

```ink
VAR cruelty = 0
VAR prestige = 0
VAR fear = 0
VAR zhao_gao = 0
VAR clan_support = 0
VAR ziying = 0
VAR zhang_han = 0
VAR meng_yi = 0
VAR strategy = 0
VAR zhao_gao_evidence = 0
```

变量含义：

| 变量 | 中文名 | 用途 |
| --- | --- | --- |
| `cruelty` | 残暴值 | 影响 HE 锁死、BE 触发和人物评价 |
| `prestige` | 威望值 | 影响朝堂态度、反抗赵高和明君线 |
| `fear` | 恐惧值 | 影响反抗选项、精神崩溃和亡国线 |
| `zhao_gao` | 赵高好感度 | 影响赵高信任、控制和警惕 |
| `clan_support` | 宗室支持度 | 影响宗室相关剧情和部分 HE |
| `ziying` | 子婴好感度 | 影响同盟、刺杀、谈判类结局 |
| `zhang_han` | 章邯好感度 | 影响巨鹿战局和军事路线 |
| `meng_yi` | 蒙毅好感度 | 影响告发失败线和英雄救赎 |
| `strategy` | 权谋值 | 影响隐忍线、反杀赵高和布局能力 |
| `zhao_gao_evidence` | 赵高罪证 | 影响反杀赵高时的证据充分度 |

定义基础标记列表：

```ink
LIST flags = 矫诏同谋, 隐忍待发, 知情不报, 曾试图告发, 庇护宗室, 宗室屠夫, 保李斯, 反杀赵高
```

设置入口：

```ink
-> prologue_start
```

### 验收标准

- `story/main.ink` 中包含全部 10 个全局变量。
- 变量名与本文档一致，便于后续前端读取。
- `story/main.ink` 中包含基础 `LIST flags`。
- `story/main.ink` 的入口可以跳转到序章起点。
- 文件不再只是 Task 2 的占位内容。

## Step 3.2：编写 `story/prologue.ink`

### 目标

从 `scripts/chapter0.md` 中迁移“沙丘之谋”核心可玩片段，形成可测试的序章最小剧情闭环。

### 实施内容

在 `story/prologue.ink` 中至少包含以下剧情段落：

- 沙丘之夜开场。
- 赵高出场。
- 赵高告知始皇驾崩。
- 赵高询问：“公子可想做皇帝？”
- 核心选择节点。
- 三个选择后的临时结算段落。

核心选择：

```text
A：同意矫诏
B：拒绝并告发
C：表面答应，暗中布局
```

选择 A 的建议效果：

```ink
~ flags += 矫诏同谋
~ fear += 1
~ zhao_gao += 2
```

选择 B 的建议效果：

```ink
~ fear += 1
~ meng_yi += 1
```

后续可以根据剧情细化为：

```ink
~ flags += 曾试图告发
```

选择 C 的建议效果：

```ink
~ flags += 隐忍待发
~ fear += 1
~ strategy += 1
```

每个选择都需要进入一个临时结算 knot，例如：

```ink
-> prologue_result_a
-> prologue_result_b
-> prologue_result_c
```

### 验收标准

- `story/prologue.ink` 中存在序章入口 knot，例如 `=== prologue_start ===`。
- 三个核心选择都存在。
- 三个选择都能跳转到各自的临时结算段落。
- 每个选择至少改变一个数值或标记。
- 选择 A 能获得【矫诏同谋】或对应标记。
- 选择 C 能获得【隐忍待发】或对应标记。
- 文件不迁移完整长篇正文，只保留足够验证分支和变量的最小剧情。

## Step 3.3：统一 Ink 标签格式

### 目标

在 Ink 剧情中使用统一演出标签，方便后续前端解析背景、立绘、音乐、音效和转场。

### 标签格式

统一使用 Ink 标签语法：

```ink
# bg: sha_qiu_night
# show: zhao_gao serious right
# hide: zhao_gao
# music: night_palace
# sfx: door_open
# fade: black
# shake: light
```

### 标签含义

| 标签 | 示例 | 含义 |
| --- | --- | --- |
| `bg` | `# bg: sha_qiu_night` | 切换背景 |
| `show` | `# show: zhao_gao serious right` | 显示角色立绘 |
| `hide` | `# hide: zhao_gao` | 隐藏角色立绘 |
| `music` | `# music: night_palace` | 播放背景音乐 |
| `sfx` | `# sfx: door_open` | 播放音效 |
| `fade` | `# fade: black` | 触发淡入淡出 |
| `shake` | `# shake: light` | 触发震屏 |

### 实施内容

在 `story/prologue.ink` 中至少加入：

```ink
# bg: sha_qiu_night
# show: zhao_gao serious right
```

可选加入：

```ink
# show: huhai anxious left
# music: night_palace
# sfx: door_open
```

### 验收标准

- `story/prologue.ink` 至少包含一个 `# bg:` 标签。
- `story/prologue.ink` 至少包含一个 `# show:` 标签。
- 标签格式与 `src/engine/tags.ts` 的解析约定一致。
- 未使用文件路径作为标签值，只使用素材 ID。

## Task 3 总体验收标准

Task 3 完成时应满足：

- `story/main.ink` 已定义全局变量和标记列表。
- `story/main.ink` 已设置序章入口。
- `story/prologue.ink` 已包含序章核心选择节点。
- A/B/C 三个选择都能从脚本结构上走通。
- 每个选择至少改变一个数值或标记。
- `story/prologue.ink` 至少包含一个背景标签和一个立绘标签。
- Ink 文件不再是空占位文件。
- 未修改 `scripts/` 原始 Markdown 剧本。

## 建议验证方式

在未接入 Ink 编译器前，先进行静态检查：

```bash
rg -n "VAR cruelty|VAR prestige|VAR fear|LIST flags|-> prologue_start" story/main.ink
rg -n "prologue_start|同意矫诏|拒绝并告发|表面答应|# bg:|# show:" story/prologue.ink
```

接入 Ink 编译器后，再补充编译验证：

```bash
npm run story:build
```

如果暂时没有 `story:build` 脚本，本任务只要求脚本结构和内容满足上述验收标准。
