# Task 11：第一章迁移 ✅

## 任务目标

迁移第一章的最小可玩片段，验证序章选择能够影响第一章选项、变量、标记和路线。

Task 11 完成后，玩家应能：

- 从序章结算进入第一章。
- 游玩“扶苏处置”节点。
- 游玩“蒙氏兄弟”节点。
- 看到序章标记影响第一章可选项。
- 看到第一章选择带来的数值和标记变化。

## 任务范围

需要涉及的文件：

```text
scripts/chapter1.md
scripts/chapter_outline.md
story/main.ink
story/prologue.ink
story/chapter1.ink
data/flags.json
data/stats.json
src/engine/debug.ts
```

可能涉及：

```text
data/endings.json
src/components/DebugPanel.tsx
```

不包含：

- 第一章全文迁移。
- 第一章全部隐藏场景。
- 完整扶苏同盟长线剧情。
- 第一章正式美术和音乐。
- 第二章迁移。

## Step 11.1：建立第一章入口

### 目标

让序章核心选择结束后，不直接 `END`，而是进入第一章。

### 实施内容

在 `story/main.ink` 中确保包含：

```ink
INCLUDE chapter1.ink
```

在 `story/prologue.ink` 的三个临时结算段落后跳转：

```ink
-> chapter1_start
```

而不是：

```ink
-> END
```

如果需要保留临时结算，可先显示结算文本，再跳转第一章。

### 验收标准

- 序章 A/B/C 任意选择后都能进入第一章。
- `story/chapter1.ink` 中存在 `=== chapter1_start ===`。
- 重新开始后仍从序章开始。
- `npm --cache ./.npm-cache run story:build` 编译通过。

## Step 11.2：迁移第一章开场

### 目标

提供第一章的最小叙事上下文，让玩家知道时间、地点和局势已经推进到二世即位。

### 来源

优先参考：

```text
scripts/chapter1.md
scripts/chapter_outline.md
```

### 实施内容

在 `story/chapter1.ink` 中写入最小开场：

- 车队返回咸阳。
- 胡亥即位为秦二世。
- 扶苏在上郡收到诏书。
- 赵高催促斩草除根。

建议加入演出标签：

```ink
# bg: xianyang_palace
# show: zhao_gao serious right
# show: huhai anxious left
```

如果素材 ID 尚未在 `data/assets.json` 中定义，可以先使用现有占位背景或不加新背景。

### 验收标准

- 进入第一章后能看到“二世即位”相关文本。
- 第一章开场不依赖完整第一章正文。
- 标签缺失素材时不白屏。

## Step 11.3：迁移扶苏处置节点

### 目标

验证序章标记影响第一章选项。

### 选项

扶苏处置节点包含：

```text
A：坚持赐死
B：改为流放
C：暗中赦免并结盟
```

### 条件规则

“暗中赦免并结盟”仅在【隐忍待发】路线可用。

Ink 条件示例：

```ink
{flags ? 隐忍待发:
* [暗中赦免并结盟]
    ...
}
```

### 建议数值和标记

坚持赐死：

```ink
~ cruelty += 1
~ fear += 1
~ flags += 坚持赐死
```

改为流放：

```ink
~ clan_support += 1
~ zhao_gao -= 1
~ flags += 扶苏流放
```

暗中赦免并结盟：

```ink
~ clan_support += 1
~ strategy += 1
~ flags += 扶苏同盟
```

### 数据表同步

如使用新标记，需要补充 `data/flags.json`：

- 坚持赐死。
- 扶苏流放。
- 扶苏同盟。

互斥组：

```text
fusu_policy
```

### 验收标准

- 非【隐忍待发】路线看不到“暗中赦免并结盟”。
- 【隐忍待发】路线能看到“暗中赦免并结盟”。
- 选择“坚持赐死”后残暴值或恐惧值变化。
- 选择“改为流放”后宗室支持或赵高好感变化。
- 选择“暗中赦免并结盟”后获得【扶苏同盟】。
- 三个选项最终都能进入蒙氏兄弟节点。

## Step 11.4：迁移蒙氏兄弟节点

### 目标

继续验证第一章选择对数值、标记和后续路线的影响。

### 选项

蒙氏兄弟节点包含：

```text
A：处死蒙恬蒙毅
B：赦免留用
C：贬为庶民
```

### 建议数值和标记

处死蒙恬蒙毅：

```ink
~ cruelty += 1
~ prestige -= 1
~ zhao_gao += 1
~ flags += 蒙氏处死
```

赦免留用：

```ink
~ prestige += 1
~ clan_support += 1
~ zhao_gao -= 1
~ meng_yi += 2
~ flags += 蒙氏留用
```

贬为庶民：

```ink
~ flags += 蒙氏免官
~ meng_yi += 1
```

如果当前已有【曾试图告发】，赦免留用可额外获得：

```ink
~ flags += 蒙毅的默契
```

### 数据表同步

如使用新标记，需要补充 `data/flags.json`：

- 蒙氏处死。
- 蒙氏留用。
- 蒙氏免官。
- 蒙毅的默契。

互斥组：

```text
meng_policy
```

### 验收标准

- 三个选项都可点击。
- 选择“处死蒙恬蒙毅”后赵高好感上升、威望下降。
- 选择“赦免留用”后宗室支持或蒙毅好感变化。
- 选择“贬为庶民”后获得【蒙氏免官】。
- 如果已有【曾试图告发】，赦免留用后获得【蒙毅的默契】。
- 三个选项都能进入第一章临时结算。

## Step 11.5：第一章临时结算

### 目标

在未迁移第二章前，为第一章提供一个清晰的阶段终点。

### 实施内容

在 `story/chapter1.ink` 中加入：

```ink
=== chapter1_result ===
第一章临时结算文本。
-> END
```

结算文本应概括：

- 扶苏处置结果。
- 蒙氏兄弟处置结果。
- 当前朝局变化。

### 验收标准

- 完成蒙氏节点后进入第一章结算。
- 结算后当前段落结束。
- 调试面板仍可显示变量、标记、可能结局。

## Step 11.6：调试面板验证

### 目标

确认第一章迁移不会破坏已有调试和存档能力。

### 验收标准

- 第一章中变量变化能在调试面板实时显示。
- 第一章中新获得的标记能在调试面板显示。
- 互斥标记冲突检测仍可用。
- 可能结局列表仍可显示。
- 保存、读档、导入、导出仍可使用。

## Task 11 总体验收标准

Task 11 完成时应满足：

- 序章 A/B/C 都能进入第一章。
- 第一章有最小开场。
- 扶苏处置节点可玩。
- “暗中赦免并结盟”仅在【隐忍待发】路线可用。
- 蒙氏兄弟节点可玩。
- 选择赦免时宗室支持或蒙毅好感变化。
- 选择处死时赵高好感和威望变化。
- 新标记已同步到 `data/flags.json`。
- `npm --cache ./.npm-cache run story:build` 编译成功。
- `npm --cache ./.npm-cache run build` 构建成功。
- 未修改 `scripts/` 原始 Markdown 剧本。

## 建议验证命令

剧情编译：

```bash
npm --cache ./.npm-cache run story:build
```

构建检查：

```bash
npm --cache ./.npm-cache run build
```

启动预览：

```bash
npm --cache ./.npm-cache run dev -- --host 127.0.0.1
```

手动验收路径：

1. 重新开始。
2. 序章选择“同意矫诏”。
3. 确认进入第一章。
4. 确认看不到“暗中赦免并结盟”。
5. 重新开始。
6. 序章选择“表面答应，暗中布局”。
7. 确认进入第一章。
8. 确认能看到“暗中赦免并结盟”。
9. 选择“暗中赦免并结盟”。
10. 选择“赦免留用”。
11. 确认宗室支持、蒙毅好感或相关标记变化。
12. 保存并读档，确认仍能恢复第一章状态。
