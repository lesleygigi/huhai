## Step 12.1：基础视觉风格 ✅

### 目标

形成稳定、可读、可交互的视觉小说阅读界面。

### 实施内容

优化以下区域：

- 背景层。
- 立绘层。
- 标题区。
- 文本框。
- 选项按钮。
- 存档面板。
- 调试面板。

具体要求：

- 背景铺满屏幕。
- 立绘不遮挡文本和选项。
- 文本框可读性高。
- 文本框长文本可滚动。
- 选项按钮清晰，点击区域足够大。
- 按钮 hover 不导致布局跳动。
- 移动端不横向溢出。
- 调试面板在移动端不阻挡主要选择。

### 验收标准

- 桌面端可以正常阅读剧情文本。
- 桌面端可以正常点击选项。
- 移动端宽度下不出现横向滚动。
- 文本框内容过长时可以滚动。
- 选项按钮不会被调试面板或存档面板遮挡。
- 立绘层不阻挡点击。
- `npm --cache ./.npm-cache run build` 构建成功。

## Step 12.2：对话历史数据 ✅

### 目标

保存已显示文本，供玩家回看。

### 实施内容

在 `GameView` 中维护对话历史：

```ts
type DialogueHistoryItem = {
  id: number;
  lines: string[];
  choice?: string;
};
```

记录规则：

- 每次获得新的 `StorySnapshot.lines` 时追加到历史。
- 玩家点击选项时，可以把选择文本记录进历史。
- 重新开始时清空历史。
- 读档/导入时如果存档中没有对话历史，可从当前 snapshot 重新开始记录。

最低可接受实现：

- 保存最近若干批次文本。
- 显示当前会话中已经读过的文本。

### 验收标准

- 页面游玩过程中会累积对话历史。
- 点击选项后，历史中能看到之前文本或选择。
- 重新开始后历史清空。
- 历史记录不会重复追加同一批文本。

## Step 12.3：对话历史面板 ✅

### 目标

玩家可以打开面板回看已读文本。

### 实施内容

新增 `HistoryPanel` 组件。

功能：

- 打开/关闭历史面板。
- 显示最近若干条剧情文本。
- 显示玩家选择文本。
- 内容过长时可滚动。

建议 UI：

```text
历史
[关闭]
1. 公元前210年，七月，丙寅。
2. 赵高：（打断）“陛下驾崩了。”
选择：同意矫诏
```

### 验收标准

- 页面上存在“历史”按钮。
- 点击“历史”按钮可以打开历史面板。
- 历史面板显示之前读过的文本。
- 历史面板显示玩家选择。
- 点击关闭后返回游戏界面。
- 历史面板移动端不横向溢出。

## Step 12.4：设置数据结构 ✅

### 目标

定义基础体验设置，并保存到本地。

### 实施内容

新增或扩展设置类型：

```ts
type GameSettings = {
  fontSize: "small" | "medium" | "large";
  textSpeed: "instant" | "normal" | "slow";
  bgmVolume: number;
  sfxVolume: number;
  muted: boolean;
};
```

建议默认值：

```ts
const defaultSettings = {
  fontSize: "medium",
  textSpeed: "instant",
  bgmVolume: 0.7,
  sfxVolume: 0.8,
  muted: true
};
```

本地存储 key：

```text
huhai-settings
```

### 验收标准

- 设置类型存在。
- 有默认设置。
- 设置可写入 `localStorage`。
- 设置可从 `localStorage` 读取。
- 无效设置不会导致页面白屏。

## Step 12.5：设置面板 ✅

### 目标

提供基础体验设置入口。

### 实施内容

新增 `SettingsPanel` 组件。

功能：

- 打开/关闭设置面板。
- 字号设置。
- 文本速度设置。
- BGM 音量设置。
- SFX 音量设置。
- 静音开关。
- 保存设置到本地。

最低可接受实现：

- 字号可以改变文本框字体大小。
- 静音设置可以同步当前音频状态按钮。
- 音量值可以保存但不必实际播放音频。

### 验收标准

- 页面上存在“设置”按钮。
- 点击后打开设置面板。
- 可以调整字号。
- 可以调整 BGM 音量。
- 可以调整 SFX 音量。
- 可以切换静音。
- 设置保存后刷新页面仍然保留。
- 设置面板移动端不横向溢出。

## Step 12.6：设置应用到界面 ✅

### 目标

让设置不只是保存，还能影响当前界面。

### 实施内容

至少应用：

- `fontSize` 影响文本框字号。
- `muted` 影响音频状态显示。

可选应用：

- `textSpeed` 用于后续逐字显示。
- `bgmVolume` 和 `sfxVolume` 预留给实际音频播放。

建议通过 class 或 CSS 变量：

```tsx
<main className={`game-view font-${settings.fontSize}`}>
```

或：

```tsx
style={{ "--reader-font-size": "18px" }}
```

### 验收标准

- 切换字号后文本框字号变化。
- 切换静音后音频状态按钮显示同步。
- 刷新页面后设置仍保留。
