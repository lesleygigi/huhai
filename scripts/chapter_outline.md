# 《胡亥模拟器》章节大纲（主线校订版）

*本稿仅依据已校对完成的胡亥主线与隐忍线整理，不包含 `b1`、`b1-2`、`b2` 线内容。上述三条序章分支及其后续独立走向，当前视为“待校对内容”，暂不并入本总纲。*

## 一、总纲说明

### 1. 适用范围

- 本大纲适用于：
  - 序章主线 `A`“同意矫诏”

- 本大纲暂不适用于：
  - `b1`：扶苏即位 IF 线
  - `b1-2`：告发未果后回落主线的旧稿支线
  - `b2`：拒绝后沉默的旧稿支线

### 2. 当前校订口径

- 时间线以已校对章节为准，不再沿用旧稿中的错误跨章纪年。
- 第五章已剥离扶苏 IF 结局；扶苏 IF 结局统一归入扶苏剧本第五章处理。
- 主线保留“普通主线”与“隐忍线”两套推进，但二者共享同一历史主干。

## 二、序章：沙丘之夜

### 时间线

- 公元前210年，七月，丙寅
- 公元前210年，七月，丙寅次日，清晨

### 剧情概要

秦始皇死于沙丘。赵高当夜召见胡亥，提出扣下始皇遗诏、伪造诏命、改立胡亥的方案。李斯随后入局，三人形成沙丘之谋。对主线与隐忍线而言，核心不再是“要不要揭发”，而是“接受这个局面后，如何定扶苏、蒙恬之命，以及胡亥是否从一开始就准备反制赵高”。

### 场景结构

1. 开场：始皇帝崩，秘不发丧
2. 场景一：赵高夜召胡亥
3. 场景二：李斯入局，沙丘密谋成形
4. 核心选择：是否与赵高合作
5. 场景二续：矫诏定策
6. 场景三：停棺密室，胡亥第一次直面帝位与恐惧
7. 场景四：车队启程返京

### 核心选择

#### 选择一：沙丘之谋

- `A 同意矫诏`
  - 获得【矫诏同谋】
  - 直接进入主线
- `C 表面答应，暗中布局`
  - 获得【隐忍待发】
  - 开启隐忍线专属数值与后续“反杀赵高”前提

#### 选择二：矫诏定策

- `赐死扶苏，囚禁蒙恬`
  - 扶苏死亡线起点
- `流放扶苏，削去官职`
  - 扶苏流放巴蜀线起点
- `扣下原诏，拖延待变`
  - 扶苏命运暂悬，为第一章制造不确定性

### 本章作用

- 完成胡亥成为“矫诏共同体成员”的历史起点。
- 明确扶苏三种状态，为第一章与后续分支提供前提。
- 仅隐忍线获得后续反制赵高所需的最初布局资格。

## 三、第一章：二世即位

### 时间线

- 公元前210年，八月上旬至中旬

### 剧情概要

车队返抵咸阳，朝廷在秘不发丧与仓促即位之间维持表面秩序。胡亥继位后，必须先处理扶苏余波，再决定蒙恬、蒙毅的命运。普通主线在这一章确立“依赖赵高维持政局”的基本姿态；隐忍线则开始秘密记录赵高罪行，并与子婴建立最初联系。

### 场景结构

1. 场景一：灵堂与即位前夕
2. 场景二：偏殿，承接序章三种扶苏状态
3. 场景三：章台殿，首次临朝
4. 核心选择：蒙氏兄弟的处置
5. 场景四：寝殿独处，冯去疾进谏
6. 隐藏场景一：秘密记录
7. 场景五：偏殿，赵高进一步收束朝政
8. 隐藏场景二：与子婴初次密会

### 核心选择

#### 蒙氏兄弟的处置

- `A 处死蒙恬蒙毅`
  - 最贴近赵高路线
  - 朝中武臣进一步寒心
- `B 赦免留用`
  - 保留蒙氏政治与军事余脉
  - 为后续“英雄救赎”等路线保留条件
- `C 贬为庶民`
  - 折中方案
  - 避免立即流血，但失去蒙氏直接助力

### 隐忍线新增

- 获得【秘密记录】
- 获得【子婴同盟】

### 本章作用

- 将序章的“非法即位”转化为正式政治现实。
- 通过蒙氏处置决定军方与旧臣是否仍有回头空间。
- 通过隐忍线隐藏场景，为第二章起的长期反赵布局准备证据与盟友。

## 四、第二章：血洗宗室

### 时间线

- 公元前210年，秋末至公元前209年，春

### 剧情概要

胡亥已即位数月，但皇权并未稳固。赵高借“宗室威胁”推动清洗嬴姓诸公子，进一步逼迫胡亥与宗族切割。此后又通过刺客事件和工程争议加深胡亥的不安全感。子婴在这一章从“谨慎观察者”转为真正的潜在政治盟友。

### 场景结构

1. 场景一：寝殿，赵高呈宗室名单
2. 场景二：偏殿，赵高与李斯围绕宗室问题施压
3. 核心选择一：宗室屠戮
4. 场景三：寝殿夜谈、公子高诗赋、刺客事件
5. 隐藏场景一：借彻查禁卫安插眼线
6. 场景四：章台殿，阿房宫与骊山工程之争
7. 核心选择二：大兴土木
8. 场景五：子婴菜园，密谈与提醒
9. 场景六：密室，整理罪证与长期布局

### 核心选择

#### 选择一：宗室处置

- `A 大开杀戒`
  - 获得【宗室屠夫】
  - 直接恶化后期大量结局口碑与宗室支持
- `B 只杀威胁者`
  - 获得【软禁宗室】
  - 历史感更强，但仍有血债
- `C 拒绝并保护宗室`
  - 获得【庇护宗室】
  - 强化子婴与宗室支持
  - 加深与赵高的裂痕

#### 选择二：工程政策

- `A 继续工程`
  - 民怨延续
  - 延续始皇旧政惯性
- `B 暂缓休养`
  - 缓和民力消耗
  - 为后续“仁政”评价提供基础
- `C 改革税制`
  - 获得【触动利益】
  - 稳定底层但得罪豪右与旧利益集团

### 隐忍线新增

- 通过刺客事件反查禁卫
- 获得【禁卫眼线】
- 累积更多【赵高罪证】

### 本章作用

- 决定胡亥与宗室是否彻底决裂。
- 决定后续天下叛乱爆发时，朝中与民间是否还有人愿意支持胡亥。
- 完成隐忍线中“证据、眼线、子婴”三套反赵基础配置。

## 五、第三章：烽火燎原

### 时间线

- 秦二世元年，七月，至公元前208年，定陶之战前后

### 剧情概要

陈胜、吴广起兵后，秦朝第一次遭遇真正意义上的天下性崩塌。胡亥必须从“宫廷政治”转向“帝国危机管理”。本章上半以“秦二世元年七月”的大泽乡起事为硬锚点，中段决定李斯与赵高谁能留下，下半推进到公元前208年定陶战局，并正式分裂为“赵高存活线”与“赵高已死线”。

### 场景结构

1. 场景一：大泽乡起事
2. 场景二：章台殿，关东军报震动朝堂
3. 核心选择一：应对起义
4. 场景三：偏殿，赵高借李斯案逼宫
5. 核心选择二：李斯之死
6. 场景四：章邯战报
7. 场景五：章邯求援
8. 核心选择三：章邯求援之应对
9. 隐藏场景：赵高离京后的行动
10. 场景六：子婴菜园收束

### 核心选择

#### 选择一：应对起义

- `A 全力镇压`
  - 获得【重用章邯】
  - 保留军事解决空间
- `B 安抚招安`
  - 获得【软弱可欺】
  - 可短缓局势，但削弱朝廷威望
- `C 置之不理`
  - 获得【坐视叛乱】
  - 大幅恶化后续天下局势

#### 选择二：李斯之死

- `A 处死李斯`
  - 获得【诛杀李斯】
  - 进入赵高存活线
- `B 保李斯`
  - 获得【保李斯】
  - 仍进入赵高存活线，但赵高敌意上升
- `C 借机除掉赵高`
  - 需隐忍线与前置条件支持
  - 获得【反杀赵高】
  - 进入赵高已死线

#### 选择三：章邯求援

赵高存活线与赵高已死线都围绕同一问题展开，但口径不同：

- `A 全力增援`
  - 获得【全力支持章邯】
- `B 拒绝增援`
  - 获得【猜忌章邯】
- `C 派赵高监军`
  - 仅赵高存活线可选
  - 获得【调虎离山】

### 本章作用

- 决定大秦是继续在赵高控制下腐烂，还是被胡亥提前夺回主动权。
- 决定章邯这支最后主力是否还能成为第五章的依托。
- 让子婴从“可疑但温和的宗室”升级为“真正理解局势的人”。

## 六、第四章：巨鹿危局

### 时间线

- 秦二世三年，巨鹿战局后段至八月己亥前后

### 剧情概要

本章承接第三章末的两种大状态：

- 路线一：赵高仍存活，胡亥仍被困于其权势之下
- 路线二：赵高已死，胡亥开始真正意义上的亲政

两线都以“王离兵败、章邯军数却后，朝廷如何应对河北败局”为共同背景，但政治重心完全不同。前者重在“如何摆脱赵高，并在败报后争夺朝堂解释权”，后者重在“如何在亲政后决定国政方向，并判断是否继续救章邯”。本章不再沿用旧稿“先指鹿、后巨鹿战报”的排序。

### 路线一：赵高存活线

#### 场景结构

1. 场景一：章台殿，败报入朝后的“指鹿为马”
2. 核心选择一：如何回应赵高
3. 场景二：寝殿夜谈，子婴献策
4. 核心选择二：破局之策
5. 专属场景：章邯回师线 / 雍城对峙线 / 宫中刺杀线
6. 场景三：棘原再报
7. 核心选择三：棘原求援与河北战局之援

#### 核心选择

- `A 坚持说鹿`
  - 获得【指鹿为鹿】
- `B 违心说马`
  - 获得【指鹿为马】
- `C 反将一军`
  - 获得【反将一军】

随后进入破局三策：

- `A 密诏章邯回师`
  - 获得【密诏章邯】
- `B 离京出巡`
  - 获得【离京出巡】
- `C 宫中刺杀`
  - 获得【宫中刺杀】
  - 成功则提前重掌大权
  - 失败则在第四章内直接落入 `BE·傀儡至死`

最后进入棘原求援后的决策：

- `A 亲征`
  - 获得【亲征】
- `B 派赵高出征监军`
  - 获得【赵高监军】
- `C 拒绝增援`
  - 获得【坐视章邯】

### 路线二：赵高已死线

#### 场景结构

1. 场景一：章台殿亲政
2. 场景二：偏殿，李斯与削藩策
3. 场景三：子婴菜园，改法之议
4. 核心选择：治国之路
5. 场景四：棘原求援
6. 核心选择：是否亲征、是否增援

#### 核心选择

- `A 削藩集权`
  - 李斯路线
- `B 推恩分封`
  - 子婴路线
- `C 改秦法，与民休息`
  - 仁君路线

随后进入棘原求援后的决策：

- `A 亲征`
- `B 派兵增援，不亲征`
- `C 拒绝增援`

### 本章作用

- 赵高存活线解决“还能不能脱身，以及如何在败报后夺回朝堂解释权”。
- 赵高已死线解决“脱身之后要把国家带向哪里，以及是否继续承担河北败局”。
- 两条线最终都汇入第五章，但导向的开局状态完全不同。

## 七、第五章：大秦的余烬

### 时间线

- 秦二世三年，八月己亥后，至其后数年

### 剧情概要

第五章不再是单一场景，而是按第四章结束状态分成四条收束路线。它既处理秦帝国最后的军事与政治选择，也承担整部作品的结局判定功能。历史口径上，本章入口统一承接第四章“八月己亥后”的残局，而不再把“王离未败时的巨鹿危机”误写成终章开场。扶苏 IF 线结局已不在本章，而由扶苏独立剧本承担。

### 状态分流

1. 明君线：赵高已死，且胡亥亲征巨鹿
2. 傀儡翻身线：赵高离京监军，胡亥坐镇咸阳
3. 逃亡线：胡亥已逃离咸阳
4. 亡国线：赵高仍掌权，胡亥困于宫中

### 各线结构

#### 1. 明君线

- 场景一：函谷关外大营
- 核心选择：巨鹿决战
  - `围而不战`
  - `主动出击`
- 结局池：
  - `HE·明君逆袭`
  - `HE·重塑天下`
  - `TE·章邯之降`
  - `HE·隐龙出渊（隐忍线专属）`
  - `HE·英雄救赎`

#### 2. 傀儡翻身线

- 场景一：咸阳宫清洗赵党
- 核心选择：清洗策略
  - `雷霆手段`
  - `分化瓦解`
- 结局池：
  - `HE·傀儡翻身`
  - `HE·借刀杀人（隐忍线专属）`
  - `附加片段：隐忍变体`

#### 3. 逃亡线

- 场景一：雪夜脱逃
- 核心选择：逃亡之路
  - `南下汉中`
  - `东出函谷投章邯`
  - `隐姓埋名`
  - `隐入暗处（隐忍线专属）`
- 结局池：
  - `HE·巴蜀之主`
  - `HE·东渡沧海`
  - `HE·北方之狼`
  - `HE·东山再起（隐忍线专属）`

#### 4. 亡国线

- 场景一：望夷宫雪夜
- 核心选择：望夷宫终局
  - `伏剑自刎`
  - `拼死抵抗`
  - `设法出逃`
  - `与赵高谈判`
- 结局池：
  - `TE·真实的二世`
  - `TE·迟来的觉醒`
  - `BE·众叛亲离`
  - `TE·子婴的继承`
  - `HE·急流勇退`
  - 以及特殊条件结局：
    - `BE·宗室屠夫`
    - `BE·六国复仇`
    - `BE·亡国罪人`
    - `BE·坠入深渊`
    - `BE·断子绝孙`
    - `BE·傀儡至死`
    - `TE·隐忍终老`
    - `BE·功亏一篑`

### 结局总数

- 本篇第五章共 24 个结局
- 不含扶苏 IF 线结局

### 本章作用

- 统一回收前四章所有关键标记、人物生死与政治取向。
- 让“普通主线”与“隐忍线”在同一历史框架内获得不同层级的结局表达。
- 结束胡亥主线正文，并把扶苏 IF 线明确留给独立剧本处理。
